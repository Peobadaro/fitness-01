# Fitness Tracker

Um aplicativo web para acompanhamento de treinos inspirado no Apple Fitness.

## Funcionalidades

- Visualização de resumo diário de atividades
- Acompanhamento de calorias, exercícios e tempo em pé
- Plano de treino detalhado
- Interface responsiva otimizada para dispositivos móveis

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como usar

1. Clone o repositório
2. Abra o arquivo `index.html` em seu navegador
3. Para desenvolvimento, recomenda-se usar um servidor local
